# 🛒 ShopSphere - E-Commerce Product Store

## 📌 Project Overview

ShopSphere is a frontend-based e-commerce website developed using:

- HTML5
- CSS3
- JavaScript
- LocalStorage

The project simulates an online shopping platform where users
can browse products, search products, filter products, view
product details, add products to cart and complete a simulated
checkout process.

---

# 🎯 Objectives

The main objectives are:

1. Build a responsive e-commerce website.
2. Practice HTML page structure.
3. Practice CSS layout and responsive design.
4. Implement JavaScript DOM manipulation.
5. Implement search and filtering.
6. Implement shopping cart functionality.
7. Use LocalStorage to persist cart data.
8. Implement a simulated checkout process.

---

# 🛠️ Technologies

HTML5
